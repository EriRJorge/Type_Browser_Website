# Type Browser - Landing Page

This repository contains the source code for the official promotional website for the **Type Browser**, a privacy-focused desktop web browser. This landing page is designed to be modern, visually engaging, and informative, showcasing the key features of the Type Browser application.

**[➡️ View Live Demo (Placeholder)](https://your-github-username.github.io/Type_Browser_Web/)**

## ✨ Website Features

- **Visually Engaging Design**: A sleek, dark-themed UI that reflects the browser's modern aesthetic.
- **Interactive Particle Background**: A dynamic, animated background of interconnected particles that responds to mouse movement, creating an immersive experience.
- **Responsive Layout**: The site is fully responsive and optimized for a seamless experience on desktops, tablets, and mobile devices.
- **Smooth Scrolling & Animations**:
  - Smooth scrolling for anchor links.
  - On-scroll reveal animations for feature cards and other elements.
  - Interactive hover effects on buttons and navigation links.
- **Mobile-First Navigation**: A clean, functional hamburger menu for smaller screens.
- **Optimized Code**: Organized and clean HTML, CSS, and JavaScript, with CSS variables and a structured file system.

## 🛠️ Technologies Used

- **HTML5**: Structured and semantic markup.
- **CSS3**: Modern styling techniques including Flexbox, Grid, custom properties, and keyframe animations for a dynamic and responsive layout.
- **JavaScript (ES6+)**: Powers the interactive features, including the particle background, scroll animations, and mobile navigation.
- **No Frameworks**: Built with vanilla HTML, CSS, and JavaScript for a lightweight and fast-loading experience.

## 🚀 Getting Started

To view or work on this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/EriRJorge/Type_Browser_Website.git
   cd Type_Browser_Website
   ```

2. **Open the website:**
   Simply open the `index.html` file in your favorite web browser.
   ```bash
   # On Windows
   start index.html

   # On macOS
   open index.html

   # On Linux
   xdg-open index.html
   ```

3. **Download the application:**
   Select the download button for Windows, macOS, or Linux. The platform
   packages are published as assets on the Type Browser GitHub release.

4. **For Development (Recommended):**
   For a better development experience with live reloading, you can use a simple local server. If you have VS Code, the "Live Server" extension is a great option.
